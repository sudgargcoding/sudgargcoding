# Hi, I'm Sudhanshu Garg 👋

Software architect and tech lead based in **Singapore**, with 21+ years of experience across embedded and networking systems, distributed platforms, cloud-native architecture and enterprise modernization. These days I spend most of my time on cloud migration, AWS serverless platforms, and applied GenAI (RAG and AI-assisted engineering) in enterprise settings.

I like connecting engineering decisions to business needs, prototyping ideas quickly to see whether they hold up, and writing down what I learn so others can reuse it.

## What I work on

- **Architecture and platforms:** distributed systems, microservices, cloud-native design, API and platform design, architecture decision records, observability
- **Cloud:** AWS (serverless, migration), Azure, CI/CD, Docker, cost and sustainability practices
- **GenAI:** retrieval-augmented generation (RAG), LLM observability and evaluation, document processing, AI-assisted software development
- **Foundations:** C/C++, Python, Java; cloud-native, distributed systems, IoT, embedded and real-time software
